# Gadget Land — Front-End Portfolio Demo

نسخه‌ی عمومی و نمایشی گجت‌لند برای GitHub Pages.

- HTML / CSS / JavaScript frontend
- داده‌های محصولات به‌صورت local و ساختگی
- بدون PHP، API، دیتابیس و پنل مدیریت
- سبد خرید و علاقه‌مندی‌ها فقط در LocalStorage مرورگر
- مناسب برای نمایش پروژه در رزومه و پورتفولیو

> این مخزن نسخه‌ی Demo است و به سرور فروشگاه واقعی متصل نیست.
