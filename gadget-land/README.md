# Gadget Land Store

فروشگاه کامل فارسی و RTL برای لوازم جانبی موبایل با رابط اصلی گجت‌لند و موتور PHP/MySQL.

## امکانات

- کاتالوگ پویا، جست‌وجو، مرتب‌سازی و دسته‌بندی چندسطحی
- محصول، تنوع، گالری، موجودی، ویژگی، برند و برچسب
- سبد خرید پایدار، تسویه‌حساب و محاسبه قطعی مبلغ در سرور
- حساب مشتری، OTP، آدرس‌ها، علاقه‌مندی‌ها، دیدگاه‌ها و پیگیری سفارش
- پنل مدیریت محصولات، سفارش‌ها، کاربران، دیدگاه‌ها، تنظیمات، پرداخت و پیامک
- درگاه sandbox برای توسعه و اتصال وندار برای محیط عملیاتی
- CSRF، نشست امن، کوئری آماده، محدودسازی OTP و جلوگیری از اجرای فایل در uploads

برای نصب روی هاست، دو فایل `dist/installer.php` و `dist/gadgetland-package.zip` را در یک پوشه یا ساب‌دامین خالی آپلود کنید و نصب‌کننده را باز کنید. حداقل نسخه PHP برابر 7.4 است. راهنمای کامل در [INSTALL-FA.md](INSTALL-FA.md) قرار دارد.

فایل‌های محرمانه `api/config.local.php` و `api/.installed` عمداً در بسته و Git نگهداری نمی‌شوند.
